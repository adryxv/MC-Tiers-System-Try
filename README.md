# Minecraft Tier System

## Español

Programa en Java que calcula los puntos y el rango de un jugador según su nivel en diferentes modalidades de Minecraft.

El usuario introduce el tier (1-5) y selecciona si es High o Low. El programa calcula los puntos correspondientes de cada modalidad y finalmente muestra el total de puntos y el título obtenido.

### Modalidades

- Sword
- Axe
- Pot
- UHC
- NethOP
- SMP
- Mace
- Vanilla

### Objetivo

Este proyecto ha sido creado como práctica de programación durante el primer curso de DAM.

---

## English

A Java program that calculates a player's points and rank based on their level in different Minecraft game modes.

The user enters their tier (1-5) and selects whether it is High or Low. The program calculates the corresponding points for each game mode and finally displays the total points and the title achieved.

### Game Modes

- Sword
- Axe
- Pot
- UHC
- NethOP
- SMP
- Mace
- Vanilla

### Purpose

This project was created as a programming practice project during the first year of DAM.
